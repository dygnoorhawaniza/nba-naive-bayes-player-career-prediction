# Dataset

Place the prepared dataset here as:

`extracted_nba_players_data.csv`

Expected target column:

`target_5yrs`

The source exercise describes 1,341 NBA player observations and 10 predictor columns after feature engineering. The dataset itself is not included in this repository.

The original exercise states that the data comes from rookie-year performance statistics and that `target_5yrs` indicates whether a player's NBA career lasted five years or more.
